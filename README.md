# seungyeopkang.github.io

Personal academic homepage, served by GitHub Pages at https://seungyeopkang.github.io.

- The whole site is `index.html`, a static page with no build step.
- Profile photo: add `assets/profile.jpg` (square, at least 400 × 400). Until it exists the page shows the initials "SK".
- When a paper's status changes, edit its tag (`Under review`, `Manuscript`, ...) and the "Last updated" line.
